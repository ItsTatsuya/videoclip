A clipping script for mpv

Keep the moment.
Skip the video editor.

Mark a start and end while you watch. Save a video, extract the audio, or share a clip — right from mpv.

One command. Ready to clip.

Paste this into PowerShell as your normal user and press Enter.

& ([scriptblock]::Create((Invoke-RestMethod 'https://itstatsuya.github.io/videoclip/install.ps1')))

No Git needed. The installer downloads Videoclip, creates script-opts, and keeps your saved preferences. Run the same command to update.

Already have mpv installed? You’re set. This installs the plugin, not the player. Read the installer.

Your first clip, in three steps.

01 / OPEN

Start with a video

Restart mpv after installing. Open a video and press c for the clipping menu.

02 / SELECT

Choose the moment

Seek to the beginning and press s. Seek to the end and press e. Preview with l.

03 / SAVE

Make it yours

Press c to save video or a for audio. Open preferences with p, then press s to save settings.

Portable mpv or a custom configuration folder?

Windows detects MPV_HOME, or a portable_config next to mpv found on PATH or running. Otherwise it uses %APPDATA%/mpv. For a portable player that cannot be detected, specify its folder:

& ([scriptblock]::Create((Invoke-RestMethod 'https://itstatsuya.github.io/videoclip/install.ps1'))) -ConfigDir 'D:/Apps/mpv/portable_config'

Linux/macOS respects MPV_HOME and XDG_CONFIG_HOME. You can also supply a directory:

curl -fsSL https://itstatsuya.github.io/videoclip/install.sh | sh -s -- '/path/to/mpv-config'
What happens when I update?

Run the same install command again. Your preferences remain in script-opts/videoclip.conf. The previous plugin is kept in videoclip-backups in the mpv configuration directory. Git checkouts are left alone; use git pull for those installs.

Do I need FFmpeg or an NVIDIA GPU?

No. Standard exports use mpv and your CPU. FFmpeg is optional for stream copy and the FFmpeg backend. NVIDIA NVENC is optional for MP4 encoding. Uploads need cURL. See the README for settings and troubleshooting.
